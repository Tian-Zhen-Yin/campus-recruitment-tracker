秋招一键收录插件｜安装说明（Chrome / Edge）

一、只需安装一次

Chrome：
1. 在地址栏输入 chrome://extensions 并回车。
2. 打开页面右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后直接包含 manifest.json、popup.js 和 background.js 的插件文件夹。
5. 打开插件的“详情”，开启“允许访问文件网址”。
6. 在浏览器右上角扩展程序菜单里，把“秋招一键收录”固定到工具栏。

Edge：
1. 在地址栏输入 edge://extensions 并回车。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择解压后直接包含 manifest.json、popup.js 和 background.js 的插件文件夹。
5. 打开插件的“详细信息”，开启“允许访问文件 URL”。

二、平时怎么用

方法一：从管理器发起识别
1. 用 Chrome 或 Edge 打开秋招投递管理器。插件会自动记住这台电脑上的实际文件位置。
2. 点击右上角“识别投递网址”。
3. 粘贴岗位详情或投递详情页网址，点击“开始识别”。
4. 管理器会显示识别出的公司、岗位、投递日期、状态、城市和原网址。
5. 动态招聘页面会等待内容加载后再识别；无法确认的岗位或日期会留空，请检查后再保存，不会自动填成当天。
5. 检查内容，补充需要的信息，然后点击“保存记录”。

方法二：从岗位页面一键收录
1. 打开任意招聘岗位详情网页。
2. 点击浏览器工具栏里的“秋招一键收录”。
3. 点击“识别并收录当前岗位”。
4. 管理器会自动打开并显示识别结果，确认后保存。

方法三：同步腾讯招聘岗位库
1. 打开管理器左侧“岗位库”。
2. 点击“同步腾讯文档”，再点击“一键同步”。
3. 插件会在后台读取指定的公开腾讯招聘文档，并把识别结果保存到浏览器本地岗位库。
4. 在岗位库中搜索岗位；投递完成后点击“记为已投递”，它才会进入正式投递记录。
5. 如果腾讯文档需要登录，请先在同一个浏览器中登录并确认能够正常查看该文档。

三、如果移动了管理器

点击插件底部的“管理器位置设置”，把新版 index.html 在浏览器地址栏里的完整地址复制进去并保存。

如果已经安装过旧版：请在扩展程序页面点击插件卡片上的“重新加载”，确认版本为 1.4.5，然后刷新管理器网页。

如果提示“文件夹错误”或“清单文件缺失”：说明选择的层级不对。应选择直接包含 manifest.json、popup.js 和 background.js 的插件文件夹，不能选择它的上级文件夹或 ZIP 压缩包。

手机说明：手机 Chrome 和 Safari 不能安装本扩展。手机请直接打开在线网页版，并使用手动新增或截图识别功能。

隐私说明：插件只在你主动点击识别或同步时读取指定网页的公开文字和职位信息；不会读取或上传你的投递记录，不接入云数据库。浏览器会显示“读取网站数据”的权限提示，这是识别详情页和腾讯招聘文档所必需的权限。
